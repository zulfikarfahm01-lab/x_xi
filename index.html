📖 Cara Menggunakan Data Asli dari Google Sheets

Karena Google Sheets tidak mengizinkan akses langsung dari website lokal (CORS), ada beberapa solusi:

🔧 Opsi 1: Gunakan CORS Proxy (termudah)

Ganti URL di kode dengan:

https://api.allorigins.win/raw?url=https://docs.google.com/spreadsheets/d/e/2PACX-1vTSLm28qEzTykpgL_Q22RtAc8Eldm_d1_DYwg9VzQTkLtUyPtg1M0ejP2d5R3D2YMJBAzVIDciFMTD5/pub?gid=0&single=true&output=csv

📂 Opsi 2: Download CSV dan simpan lokal

Download file CSV dari Google Sheets, lalu taruh di folder yang sama dengan index.html. Ganti URL dengan nama file.

🌐 Opsi 3: Gunakan GitHub Pages / Netlify

Hosting aplikasi ini di GitHub Pages atau Netlify — CORS tidak masalah di server.

Sementara ini aplikasi berjalan dengan data dummy (7 siswa dari 3 program). Anda bisa langsung mencoba fitur-fitur lengkapnya.
